-   **Dynamic Permission Enforcement:**
    -   **Backend:** A custom FastAPI middleware () intercepts API calls, maps the request path to a feature, and validates the user's permissions for the required action (inferred from the HTTP method).
    -   **Frontend:** A  provides hooks (, , etc.) to conditionally render UI components. The main sidebar navigation is dynamically filtered based on these permissions.
-   **WebRTC & WebSocket Signaling:** Used for the real-time calling feature. A FastAPI WebSocket endpoint acts as the signaling server to exchange session descriptions (SDP) and ICE candidates between peers.
-   **Feature Toggling:** A system using the  array in the database allows enabling/disabling major features like the Call Studio on a per-site basis.
