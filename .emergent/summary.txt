-   **Centralized Firewall Middleware:** A FastAPI middleware () intercepts every incoming request to apply IP/Country blocks and endpoint protection rules before the request reaches the application logic.
-   **Dynamic Route Discovery:** The backend automatically discovers all available API endpoints using  to populate the list of manageable endpoints in the firewall UI, ensuring new endpoints are automatically included.
-   **Live Session Management:** A  collection tracks active users. A unique  is added to the JWT on login and used to identify and terminate sessions via the API.
-   **Forced Interaction Flow:** The  flag in the user model, propagated through the  endpoint and React Context, allows the application to interrupt the user's flow with a mandatory action (changing their password).
